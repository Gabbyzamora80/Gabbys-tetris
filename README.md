# Gabby's Tetris

A multiplatform Tetris-style game made with Python, featuring a welcome screen, chiptune music, and sound effects.

## Features

- Welcome screen to start the game
- Background music and sound effects
- Score, lines, and levels
- Keyboard controls

## Requirements

- Python 3.10 or later
- Tkinter
- pygame-ce

## Install and run

Install the dependencies:

```bash
python -m pip install -r requirements.txt
```

Start the game:

```bash
python main.py
```

On Linux or macOS, use `python3` if `python` is not available. On Windows, you can use `py`.

## Controls

| Key | Action |
| --- | --- |
| ← / → | Move the piece |
| ↓ | Move the piece down |
| ↑ or X | Rotate clockwise |
| Z | Rotate counterclockwise |
| Space | Hard drop |
| P | Pause or resume |
| R | Restart |
| M | Toggle music |

# Gabby's Tetris

Un juego multiplataforma de bloques hecho en Python, con pantalla de bienvenida, música chiptune y efectos de sonido.

## Características

- Pantalla de bienvenida para iniciar la partida
- Música de fondo y efectos de sonido
- Puntaje, líneas y niveles
- Controles de teclado

## Requisitos

- Python 3.10 o posterior
- Tkinter
- pygame-ce

## Instalación y ejecución

Instalá las dependencias:

```bash
python -m pip install -r requirements.txt
```

Iniciá el juego:

```bash
python main.py
```

En Linux o macOS, usá `python3` si `python` no está disponible. En Windows, podés usar `py`.

## Controles

| Tecla | Acción |
| --- | --- |
| ← / → | Mover la pieza |
| ↓ | Bajar la pieza |
| ↑ o X | Girar en sentido horario |
| Z | Girar en sentido antihorario |
| Espacio | Caída rápida |
| P | Pausar o continuar |
| R | Reiniciar |
| M | Activar o desactivar la música |
